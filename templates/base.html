Mission Briefing

RUSTROID SENTINEL

Near-Earth Object Monitoring System

A high-performance Rust backend continuously extracting and analysing data from the NASA NeoWs API. It classifies potentially hazardous near-Earth objects, fires Discord alerts on critical approaches, and exposes a real-time dashboard backed by an async ETL pipeline and distributed observability.

ETL Pipeline

Extracts, transforms, and loads NASA NEO data into PostgreSQL via async Rust pipelines

Hazard Detection

Classifies NEOs into Critical / High / Medium / Low based on velocity and miss distance

Discord Alerts

Automated webhook embeds sent to Discord on critical NEO approach detection events

Observability

OpenTelemetry tracing, Prometheus metrics, and real-time velocity dashboard

Rust 1.95+ Axum PostgreSQL OpenTelemetry NASA NeoWs
